*Evidence level: dry runs against `brittonr/vermilion`; nothing was pushed.
Fixed in the same session.*

`docs/issues/` in this fork holds two populations of numbered files: 58
inherited from the parent repository, whose `github:` numbers are that
repository's, and 30 of the fork's own. Numbers 1–30 are each carried by
one file of either kind. `sync_issues.py` indexed files by number alone,
so the later file name silently won, and on a checkout without
`.sync-state.json` (every fresh clone: the sidecar is gitignored) it
treated every file as locally changed.

`scripts/sync_issues.py --push --dry-run` at f4e1c9d planned:

| Planned | Count | |
|---|---|---|
| PUSH (rewrite title and body) | 30 | 16 of them onto a *different* issue, e.g. `formal-semantics-for-the-neutral-ir.md -> #3`, which here is "Evidence pass assumes equality is always decidable…" |
| LABEL | 15 | the same wrong pairs |
| CREATE | 7 | every `github: null` file |

`--pull` planned the mirror image: fork files rewritten from unrelated
issues. The two-way default reported the pairs as conflicts and changed
nothing, which is why this stayed latent; the documented publish command
is `--push`.

### Fix

`resolve_claims` decides which local file is issue #N of the sync target
before anything is reconciled:

- the file whose title is the issue's; or
- when a single file carries N and this checkout has synced the pair
  before, that file (a retitle since the last sync).

A file that loses to another is skipped with a warning (numbered for
another repository). A lone file whose title differs from an issue this
checkout never synced is a conflict in every direction, `--push` and
`--pull` included, and its number is not pulled into a second file.

After the fix the same dry run plans 29 pushes, each a fork file onto its
own issue (28 only drop the "Generated by Claude Code" footer the GitHub
bodies carry; #17 has a later local edit), 7 creates, and 58 warnings (30
parent-numbered files skipped, 28 numbers absent here).
`tests/test_sync_issues.py` covers the five outcomes;
`docs/issues/README.md` states the rule.
